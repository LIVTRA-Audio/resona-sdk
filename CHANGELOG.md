# Changelog

Versions follow `sdk.json`. Each release is a `vX.Y.Z[-pre]` tag with a
`resona-sdk-<version>.tar.gz` archive made by `tools/release.py`.

## 1.0.0 (2026-11-16)

The first public release, for Resona Box OS 1 (platform API 1, effect module ABI 2).

- Make effects and Apps for the Resona Box in C or C++ with Creator Lab.
- Templates, examples and the source of the Box's factory App.
